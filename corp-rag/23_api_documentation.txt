API ДОКУМЕНТАЦИЯ

Базовый URL: https://api.ambralla.ru/v1

Аутентификация: Bearer Token (получается при входе в систему)

Эндпоинты:

1. GET /users — список пользователей
   Параметры: limit (int), offset (int)
   Ответ: массив объектов user

2. GET /users/{id} — получить пользователя по ID
   Ответ: объект user

3. POST /users — создать пользователя
   Тело: {"name": "Иван", "email": "ivan@mail.ru", "role": "admin"}
   Ответ: созданный пользователь с ID

4. PUT /users/{id} — обновить пользователя
   Тело: {"name": "Новое имя"}
   Ответ: обновлённый пользователь

5. DELETE /users/{id} — удалить пользователя
   Ответ: {"status": "deleted"}

Коды ошибок:
200 — успешно
201 — создано
400 — неверный запрос
401 — не авторизован
403 — недостаточно прав
404 — не найдено
429 — слишком много запросов (rate limiting)
500 — внутренняя ошибка сервера

Документация: https://api.ambralla.ru/docs (Swagger)
