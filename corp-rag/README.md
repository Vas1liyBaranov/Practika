# KnowledgeBase Pro

Корпоративная поисковая система на основе RAG (Retrieval-Augmented Generation).

## Возможности

- Загрузка документов (PDF, DOCX, TXT, MD)
- Автоматическая индексация и разбиение на фрагменты
- Поиск по документам с проверяемыми источниками
- Честный отказ при отсутствии информации
- История запросов и оценка полезности
- Eval-набор для проверки качества

## Установка

git clone <repository>
cd corp-rag
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
