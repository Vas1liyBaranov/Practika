ВНЕШНИЕ СЕРВИСЫ

1. Slack — для коммуникации (каналы: #general, #dev, #support).
2. Jira — для управления задачами (доски: разработка, тестирование, релизы).
3. GitHub — для хранения кода и ревью.
4. AWS — для хостинга (ec2, s3, rds, vpc, route53).
5. Sentry — для мониторинга ошибок.
6. Prometheus + Grafana — для мониторинга серверов.
7. Elasticsearch + Kibana — для логов.
8. Figma — для дизайн-макетов.
9. Notion — для документации и базы знаний.
10. Google Workspace — для почты и календарей.
11. Zoom — для видеозвонков.
12. Miro — для мозговых штурмов и диаграмм.

Доступ к сервисам предоставляется руководителем.
Политика безопасности: SSO через Google Workspace.
