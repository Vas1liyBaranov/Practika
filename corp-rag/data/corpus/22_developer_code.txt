КОДЕКС РАЗРАБОТЧИКА

1. Пиши читаемый код — ты не один.
2. Комментируй сложные участки (почему, а не что).
3. Не бойся задавать вопросы.
4. Проверяй код перед отправкой (самопроверка).
5. Документируй принятые решения.
6. Делись знаниями с коллегами.
7. Будь открыт к критике и конструктивным замечаниям.
8. Не оставляй технический долг без внимания.
9. Соблюдай стандарты кодирования (PEP8, Clean Code).
10. Пиши тесты для новой функциональности.
11. Используй инструменты для статического анализа (flake8, mypy, black).
12. Помни: код читается чаще, чем пишется.
13. Рефакторинг — это нормально, делай его постепенно.
14. Не пренебрегай документацией для API.
15. Уважай время коллег — не создавай шум в чатах и PR.

Цитаты:
- "Лучший код — тот, который не нужно объяснять."
- "Ты не программист, если не переписывал свой код трижды."
- "Make it work, make it right, make it fast."
- "Простые решения лучше сложных."
- "Семь раз отмерь, один раз напиши."
